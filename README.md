# Password Strength Checker

## Project Overview

This project is a simple Password Strength Checker developed in C++. It
evaluates the strength of a password based on password length, uppercase
letters, lowercase letters, numbers, and special characters.

This project was developed as part of the **DecodeLabs Cyber Security
Internship 2026 (Project 1)**.

## Objectives

-   Learn password validation techniques.
-   Understand the importance of strong passwords.
-   Practice C++ programming.
-   Improve basic cybersecurity concepts.

## Features

-   Checks password length.
-   Detects uppercase letters.
-   Detects lowercase letters.
-   Detects numeric digits.
-   Detects special characters.
-   Classifies password strength as Weak, Medium, or Strong.

## Technologies Used

-   C++
-   Standard Library
-   Visual Studio Code / Dev-C++ / Code::Blocks

## Algorithm

1.  Read the password from the user.
2.  Check the password length.
3.  Verify uppercase, lowercase, numbers, and special characters.
4.  Calculate the password strength score.
5.  Display the password strength.

## Example

### Input

    Enter Password: Hello@123

### Output

    Password Analysis
    -----------------
    Length: 9
    Uppercase: Yes
    Lowercase: Yes
    Numbers: Yes
    Symbols: Yes

    Password Strength: Strong
