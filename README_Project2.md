# Basic Encryption & Decryption using Caesar Cipher

## Project Overview

This project implements a simple Caesar Cipher algorithm in C++. It
demonstrates the basic concepts of encryption and decryption by shifting
alphabetic characters using a user-defined key.

This project was developed as part of the **DecodeLabs Cyber Security
Internship 2026 (Project 2)**.

## Objectives

-   Understand the basics of encryption and decryption.
-   Implement the Caesar Cipher algorithm.
-   Practice C++ programming.
-   Learn basic cryptography concepts.

## Features

-   Encrypt user-entered text.
-   Decrypt encrypted text back to the original text.
-   Support uppercase and lowercase letters.
-   Use a custom encryption key.
-   Preserve spaces and special characters.

## Technologies Used

-   C++
-   Standard Library
-   Visual Studio Code / Dev-C++ / Code::Blocks

## Algorithm

1.  Read text from the user.
2.  Read the encryption key.
3.  Encrypt the text using the Caesar Cipher algorithm.
4.  Display the encrypted text.
5.  Decrypt the encrypted text.
6.  Display the original text after decryption.

## Example

### Input

    Enter Text: HELLO WORLD
    Enter Key: 3

### Output

    Original Text  : HELLO WORLD
    Encrypted Text : KHOOR ZRUOG
    Decrypted Text : HELLO WORLD
